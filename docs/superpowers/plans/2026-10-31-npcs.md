# The locals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three locals in every world: people who are not agents, each working one of its stations all the time (behind its counter, seated in it, or standing beside it), fully drawn on a shared puppet, reacting to the agents, serving drinks and orders, putting on shows that draw a ring of idle agents, and stopping for a word. The `n` key turns them off and on.

**Architecture:** A world's `npcs` lists three `Npc`s: where each works (a station, a place in its frame) and its own parts (body, head, upper arm, forearm) drawn with the sketch API, plus its loops (work, a show, its own cheer) and what it serves. A shared puppet (`src/art/npc/puppet.ts`) assembles the parts for one frame; eight shared acts (`src/art/npc/acts.ts`) drive the same puppet for every local. The room planner places the locals after the decor (`placeNpcs` in `src/world/room.ts`) and keeps a standing one's floor clear. `src/world/npcs.ts` (`Locals`) runs what each local does by the life clock; `Life` gains three errands (`order`, `watch`, `natter`) and routes coffee runs to the world's drink server. The scene draws each local as a cached sprite (`npcSprite`), cut along its counter's top edge, standing on its station's box in depth order; a station a local works is drawn round a two-second loop of kept pictures, so always-worked stations cost almost nothing to send.

**Tech Stack:** TypeScript on node ≥ 23.6 (type stripping, no build), `node:test`, the project's own canvas (`src/art/canvas.ts`), the figure sketch API (`src/art/figure/paint.ts`).

**Spec:** `docs/superpowers/specs/2026-10-31-npcs-design.md`.

## Decisions (where the design left a choice)

- **Types** (`src/worlds/types.ts`): `Npc = { name, station, place, tall, bones, parts, work, show?, celebrate?, serve? }`. `NpcPlace` is `behind` (`u, v, top, edge`), `seated` (`u, v, z`, and `top, edge` if something of its station stands in front) or `standing` (`u, v`), each with an optional `look`: `out` (the default), `along` or `back`. `NpcParts` has four parts, each called `(sk, puppet, …, back)` in its own frame: `body`, `head` (origin at the neck), `upper` and `fore` for arm `k` (origin at the shoulder and the elbow, the arm along +y). `Puppet = { act, u, bob, lean, tilt, arms: [Swing, Swing], eyes, mouth, hold }`; `Swing = { sh, el }`. Arm 0 is the near one (it hands things over), arm 1 the far one (it waves).
- **Loops:** work 4–12 frames over 0.5–4 s, show 6–16 frames over 1–6 s, celebrate 4–12 frames over 0.6–2.5 s, never over 12 frames a second. Shared acts (seconds, frames): wave 1.2/8, cheer 1.2/8, flinch 0.8/6, applaud 1.6/10, talk 1.6/10, nod 1.0/6, handOver 1.6/8, beckon 1.4/8.
- **The cut:** `cut = top − z − (edge − v)` units over its feet (the edge's point in the local's screen column stands `edge − v` along and `edge − v` nearer, each dropping half a unit), applied to the painted sprite along the counter's screen slope (+½ on a right-wall station, −½ on a left-wall one), then cropped again, the anchor kept. Pixels are cleared, so the cache holds the cut picture (its key carries the cut).
- **Placement** (after the decor, so a world shell's own `planRoom` call finds the same furniture): behind and seated always fit; a standing local needs floor `NPC_R` (1.5) clear of every prop and pile, 3 from every station's spot (8 from the way in's), 3 from the spots idlers like, off the plazas, the yard and the hub, and apart from other standing locals; else it is left out. Its floor goes into the routing grid, and with whoever it serves into what workstations keep off. Whoever it serves stands 2.5 out in front of its station (3 past a standing one), the next 4 along; a show's ring centres 7 further out.
- **Rendering:** `NpcFrame` in `src/world/frame.ts`, `SceneFrame.npcs`; `npcSprite(world, frame, s, ink)` in `src/art/figure.ts` through the shared sprite cache, key `n|<art>|<act>|<frame>|<back><flip>|<cut>|<scale>|<ink>`; depth items `npc:<k>` with `on` its station's `prop:<i>` item; shadows `shadow:npc:<k>`, emotes `emote:npc:<k>`.
- **Worked stations, cheaply** (measured, see Risk 1): a station a local works animates on a loop of `CYCLE` = 12 ambient steps (two seconds), each step drawn once and placed as a kept picture (not a volatile one), so after one round it is only placed. The way in is never "worked" by its local (its door opens only for those who pass).
- **Behaviour:** `Locals` (`src/world/npcs.ts`) holds each local's acts by the life clock (a reaction lines up after what is under way; none during a show), its queue (at most two: at the counter and beside it), what it has served, its show and its word. `Life` gets errands `order`, `watch` and `natter`; a coffee run carries the local it goes to. Shows start every 120–240 s (the first as long in) once two idle agents are awake, last 20 s; up to 6 idle agents free for one (`Life.spare`: no errand but a visit) gather on a ring, joining as they come free until 6 s before the end. Being served at a counter counts as an agent's word with that local (no word straight after). A word: 35 % once a pass within 6 units of a free local's counter, at most one every 60 s an agent, 5 s long. A drink comes back as a mug while office life is on (mugs are office life's, see `sipping`); anything else, or a drink with office life off, as a heart.
- **The toggle:** `Stage.npcs` (getter and setter), `World.npcs`, `WorldOpts.npcs`, `Config.npcs`, the `n` key, saved as `npcs` in the config. Off: the locals go, every errand with one ends, a standing one's floor opens up (walkers re-plan), the stations stand idle.
- **The sample local:** the club's DJ behind the decks, the booth's body moved forward to leave room (Task 7), drawn in full.

## Risks, and how the plan meets them

1. **Bytes: three always-worked stations.** Measured on this branch (twenty at work, 150 × 46, 3 s after 15 s): marking three stations always worked cost **+10 to +13 KB a step** over none (club +13.0 KB, hell +13.3, lab +13.0, cafe +10.4), three times the design's 4 KiB. The cause: an animated prop is a *volatile* layer, a fresh picture sent every ambient step. Prototyped fix: draw it round a 12-step loop and place each step as a kept picture: **+85 bytes a step** without its particles, **+0.8 to +3.7 KB** with them (hell the worst). Task 4 builds it (with it, the club's DJ alone measured +0.9 KB a step); Task 8 tests the club; Task 17 measures every world and has a fallback (half the particles off a station only a local works) if one goes over.
2. **Old tests meet the locals.** Locals take idle agents (orders, shows, words), keep floor and keep stations worked, so existing life, office-life and stage tests could drift once their worlds get locals. The life and office-life tests' own worlds (`lively`, `dry`: the mines with fixed spots) get `npcs: []` (Task 5), in the spirit of their fixed spots; a stand-up may pull agents off a local's errand (`waiting`, Task 5); the stage test on idle stations learns about worked ones (Task 3). Every art batch runs the whole suite in a clean worktree before it is committed.
3. **The room plan moves.** Reserved floor can move workstations. Locals are placed after the decor (world shells that call `planRoom` themselves find the same furniture: tested in Task 2), reservations are whole floor cells (fractional rects would be dropped silently by the typed-array marking in `keepOut`), and tests check that desks and routing keep off a standing local.
4. **The cut and the depth order.** A local behind a counter is drawn over its station, so anything tall on the counter in front of it would be painted over. The cut follows the counter's edge on screen; the contract bounds the cut (2.5 to 9 units: legs hidden, head and shoulders shown); the art tasks keep tall things on a counter out of the local's way, and look at each local at its station on the sheet (`scripts/npc-sheet.ts`, Task 7).
5. **A local by the way in.** "Worked" would hold its door open for good: excluded (`works: false` for the entrance).
6. **Someone stuck at a counter.** A queue holds two; each waits `SERVE_WAIT` after arriving, then goes without; a serve pushes reactions lined up after it; `n` off ends every errand with a local; tested.
7. **The contract test's cost.** About 100 small renders a local (every frame of every act at s = 6). If `test/themes.test.ts` grows by more than about 15 s, check every other frame of the shared acts (they are interpolated and start and end at rest).
8. **Parallel art agents in one checkout.** Each art agent touches only its worlds' files; the coordinator checks each batch in a clean scratch worktree before committing; a failure in a file an agent does not own is someone else's, retried later.
9. **Determinism.** Every choice comes from seeded generators (the world's for the locals, each agent's own for the agents) and the life clock: tested.
10. **Import cycles.** `world/npcs.ts` imports `Life` and `Actor` as types only; `life.ts` and `stage.ts` import `Locals` and constants; `verbatimModuleSyntax` keeps type imports erased.

```ts
import { shade } from '../src/art/iso.ts';
import { rest } from '../src/art/npc/acts.ts';
import { face } from '../src/art/npc/face.ts';
import type { Pen } from '../src/art/types.ts';
import { PROP_SIZE } from '../src/world/layout.ts';
import type { SlotKind } from '../src/world/types.ts';
import type { Bones, Npc, NpcLoop, NpcPlace, NpcServe, WorldDef } from '../src/worlds/types.ts';

// Stand-in locals for tests that must not hang on how a world draws its
// own: a block of a body on two legs, a round head with a face, stick
// arms. At work the far arm swings and the head nods; a show raises both
// arms; a celebration jumps.

const TAU = Math.PI * 2;
const SKIN = '#e0a074';
const circ = (cx: number, cy: number, r: number) => (p: Pen) => p.arc(cx, cy, r, 0, TAU);

export const BONES: Bones = { neck: [0.1, -7.9], shoulders: [[-1.6, -7.3], [1.7, -7.3]], upper: 1.7, fore: 1.6 };

// Something to drink, and something not.
export const CUP: NpcServe = {
  name: 'cup',
  drink: true,
  draw(sk) {
    sk.blob((p) => p.roundRect(-0.5, -0.3, 1.0, 1.2, 0.25), '#f4efe6', { dark: '#d8cfc0', d: 0.2 });
  },
};
export const TICKET: NpcServe = {
  name: 'ticket',
  drink: false,
  draw(sk) {
    sk.blob((p) => p.rect(-0.4, -0.1, 0.8, 1.1), '#ffd34a', { line: 0.6 });
  },
};

export type StandIn = { color?: string; serve?: NpcServe; show?: 'dance' | 'watch'; celebrate?: boolean; tall?: number };

export function standIn(name: string, station: SlotKind, place: NpcPlace, o: StandIn = {}): Npc {
  const color = o.color ?? '#5a8ad8';
  const work: NpcLoop = {
    secs: 1,
    frames: 8,
    pose: (u) => ({ ...rest(), tilt: 0.1 * Math.sin(u * TAU), arms: [{ sh: 0.12, el: 0.2 }, { sh: 0.6 + 0.5 * Math.sin(u * TAU), el: 0.6 }] }),
  };
  const n: Npc = {
    name,
    station,
    place,
    tall: o.tall ?? 14,
    bones: BONES,
    parts: {
      body(sk) {
        for (const x of [0.8, -0.8]) sk.limb([x, -3.4, x, -0.4], 1.1, '#3a3f66');
        sk.blob((p) => p.roundRect(-2.0, -7.8, 4.2, 4.6, 1.2), color, { dark: shade(color, -0.25), d: 0.4 });
      },
      head(sk, p, back) {
        sk.blob(circ(0.1, -2.95, 3.2), SKIN, { dark: shade(SKIN, -0.2), d: 0.4 });
        if (!back) face(sk, { x: 0.65, y: -2.15, eyes: p.eyes, mouth: p.mouth });
      },
      upper(sk) {
        sk.limb([0, 0, 0, BONES.upper], 1.0, color);
      },
      fore(sk) {
        sk.limb([0, 0, 0, BONES.fore], 0.9, SKIN);
        sk.blob(circ(0, BONES.fore, 0.55), SKIN);
      },
    },
    work,
  };
  if (o.serve) n.serve = o.serve;
  if (o.show) {
    n.show = {
      secs: 2,
      frames: 12,
      crowd: o.show,
      pose: (u) => ({ ...rest(), bob: 0.3 * Math.abs(Math.sin(u * TAU * 2)), arms: [{ sh: 2.6, el: 0.3 }, { sh: 2.6 + 0.3 * Math.sin(u * TAU * 2), el: 0.3 }], eyes: 'happy', mouth: 'open' }),
    };
  }
  if (o.celebrate) n.celebrate = { secs: 1, frames: 6, pose: (u) => ({ ...rest(), bob: 0.5 * Math.sin(u * Math.PI), eyes: 'happy', mouth: 'open' }) };
  return n;
}

export const withLocals = (w: WorldDef, npcs: readonly Npc[]): WorldDef => ({ ...w, npcs });

// Three stand-ins any world has room for, inside their stations: one
// behind the run station pouring drinks (it has a show), a clerk seated at
// the think station handing out tickets, a smith behind the write station
// (with its own way of celebrating).
export function trio(w: WorldDef): WorldDef {
  return withLocals(w, [
    standIn('pourer', 'run', { mode: 'behind', u: 5.5, v: 2, top: 6, edge: 4 }, { color: '#d85a5a', serve: CUP, show: 'watch' }),
    standIn('clerk', 'think', { mode: 'seated', u: 6, v: 3, z: 2 }, { color: '#5ad87a', serve: TICKET }),
    standIn('smith', 'write', { mode: 'behind', u: 5.5, v: 1.5, top: 5, edge: 3 }, { color: '#d8c85a', celebrate: true }),
  ]);
}

// Stand-ins standing round the run and write stations, a few units apart,
// beside them and out in front, and one inside the run station: the
// planner keeps those it can (see placeNpcs), for tests of a local on the
// floor.
export function standers(w: WorldDef): WorldDef {
  const out: Npc[] = [];
  for (const station of ['run', 'write'] as const) {
    const { len, dep } = PROP_SIZE[station];
    const spots: Array<[number, number]> = [[-2.5, dep - 1], [len + 2.5, dep - 1], [-2.5, dep + 3], [len + 2.5, dep + 3], [len / 2 - 4, dep + 3.5], [len / 2 + 4, dep + 3.5]];
    for (const [u, v] of spots) out.push(standIn(`stander${out.length}`, station, { mode: 'standing', u, v }));
  }
  out.push(standIn('insider', 'run', { mode: 'standing', u: 5, v: 5 }));
  return withLocals(w, out);
}
```

```ts
export const hashOf = (c: Canvas) => createHash('sha256').update(c.data).digest('hex');

// Local n in `act` at `frame`, from behind or not, drawn at scale S on a
// canvas exactly NPC_BOX in size, its feet at the box's origin.
export function npcPicture(n: Npc, act: NpcAct, frame: number, back: boolean): Canvas {
  const sk = new Sketch();
  buildNpc(sk, n, puppetOf(n, act, frame), back);
  const c = new Canvas((B.x1 - B.x0) * S, (B.y1 - B.y0) * S);
  render(c, sk, [S, 0, 0, S, -B.x0 * S, -B.y0 * S], Math.max(1.5, 0.28 * S), INK);
  return c;
}

// Its painted pixels, whether any lies on the canvas's edge (the box was
// too small for it), and how high it reaches over its feet (units).
export function painted(c: Canvas): { n: number; edge: boolean; top: number } {
  let n = 0;
  let edge = false;
  let row = c.height;
  for (let y = 0; y < c.height; y++) {
    for (let x = 0; x < c.width; x++) {
      if (c.data[(y * c.width + x) * 4 + 3] < 16) continue;
      n++;
      row = Math.min(row, y);
      if (x === 0 || y === 0 || x === c.width - 1 || y === c.height - 1) edge = true;
    }
  }
  return { n, edge, top: (-B.y0 * S - row) / S };
}

// Pixels that differ between two pictures of one size.
export function differ(a: Canvas, b: Canvas): number {
  let n = 0;
  for (let o = 0; o < a.data.length; o += 4) {
    const d = Math.abs(a.data[o] - b.data[o]) + Math.abs(a.data[o + 1] - b.data[o + 1]) + Math.abs(a.data[o + 2] - b.data[o + 2]);
    if (d > 48 || Math.abs(a.data[o + 3] - b.data[o + 3]) > 32) n++;
  }
  return n;
}

// The acts a local plays: its own and the shared ones.
export function actsOf(n: Npc): NpcAct[] {
  const own: NpcAct[] = ['work'];
  if (n.show) own.push('show');
  if (n.celebrate) own.push('celebrate');
  return [...own, ...(Object.keys(ACTS) as NpcAct[])];
}

export function npcContract(w: WorldDef, n: Npc): void {
  const what = `${w.id} ${n.name}`;
  const art = w.stations[n.station];
  const { len, dep } = PROP_SIZE[n.station];
  assert.ok(/^[a-z][a-zA-Z0-9]*$/.test(n.name), `${what}: a name in camelCase`);
  assert.ok(n.tall >= 11 && n.tall <= 16, `${what}: ${n.tall} tall`);
  assert.ok(n.bones.upper > 0 && n.bones.fore > 0 && n.bones.upper + n.bones.fore <= 5, `${what}: arms ${n.bones.upper} and ${n.bones.fore} long`);
  // Where its job puts it, in its station's frame.
  const pl = n.place;
  if (pl.mode === 'standing') {
    assert.ok(pl.u <= -NPC_R || pl.u >= len + NPC_R || pl.v >= dep + NPC_R, `${what}: standing at ${pl.u}, ${pl.v}, on its station`);
  } else {
    assert.ok(pl.u >= 0.5 && pl.u <= len - 0.5 && pl.v >= 0.3 && pl.v <= dep - 0.3, `${what}: at ${pl.u}, ${pl.v}, not inside its station`);
  }
  if (pl.mode === 'seated') assert.ok(pl.z >= 0 && pl.z <= 8, `${what}: seated ${pl.z} up`);
  const cut = cutOf(pl);
  if (pl.mode === 'behind') assert.ok(cut !== undefined, `${what}: behind nothing`);
  if (cut !== undefined && pl.mode !== 'standing') {
    assert.ok(pl.edge! > pl.v && pl.edge! <= dep && pl.top! > 0 && pl.top! <= art.height, `${what}: a counter ${pl.top} high from ${pl.edge} out`);
    assert.ok(cut >= 2.5 && cut <= 9, `${what}: cut ${cut.toFixed(2)} over its feet (its legs hidden, its head and shoulders shown)`);
  }
  // Its loops.
  const loop = (name: string, lp: NpcLoop, frames: readonly [number, number], secs: readonly [number, number]) => {
    assert.ok(Number.isInteger(lp.frames) && lp.frames >= frames[0] && lp.frames <= frames[1], `${what}: ${name} in ${lp.frames} frames`);
    assert.ok(lp.secs >= secs[0] && lp.secs <= secs[1] && lp.frames / lp.secs <= 12, `${what}: ${name} in ${lp.frames} frames over ${lp.secs} s`);
  };
  loop('work', n.work, [4, 12], [0.5, 4]);
  if (n.show) {
    loop('show', n.show, [6, 16], [1, 6]);
    assert.ok(n.show.crowd === 'dance' || n.show.crowd === 'watch', `${what}: a show's crowd`);
  }
  if (n.celebrate) loop('celebrate', n.celebrate, [4, 12], [0.6, 2.5]);
  // Every frame of every act inside its box, as it is seen (from behind
  // too if it faces away; the other way round is the mirror image).
  for (const back of pl.look === 'back' ? [false, true] : [false]) {
    for (const act of actsOf(n)) {
      const lp = loopOf(n, act);
      for (let i = 0; i < lp.frames; i++) {
        const p = painted(npcPicture(n, act, i, back));
        assert.ok(p.n > 0, `${what}: ${act} ${i}${back ? ' from behind' : ''} draws nothing`);
        assert.ok(!p.edge, `${what}: ${act} ${i}${back ? ' from behind' : ''} reaches out of its box`);
      }
    }
  }
  // The same frame the same pixels; its work moves; as tall as it says.
  const work = Array.from({ length: n.work.frames }, (_, i) => npcPicture(n, 'work', i, false));
  assert.deepEqual(Array.from({ length: n.work.frames }, (_, i) => hashOf(npcPicture(n, 'work', i, false))), work.map(hashOf), `${what}: a work frame drawn two ways`);
  assert.ok(new Set(work.map(hashOf)).size >= 3, `${what}: its work does not move`);
  const top = Math.max(...work.map((c) => painted(c).top));
  assert.ok(top >= n.tall - 2 && top <= n.tall + 0.75, `${what}: ${top.toFixed(2)} tall at work, says ${n.tall}`);
  // What it serves draws, small, at its hand.
  if (n.serve) {
    assert.ok(/^[a-z][a-zA-Z0-9]*$/.test(n.serve.name), `${what}: its serve item's name`);
    const sk = new Sketch();
    n.serve.draw(sk);
    const c = new Canvas(6 * S, 6 * S);
    render(c, sk, [S, 0, 0, S, 3 * S, 3 * S], Math.max(1.5, 0.28 * S), INK);
    const p = painted(c);
    assert.ok(p.n >= S * S && !p.edge, `${what}: its ${n.serve.name} draws nothing, or reaches 3 units from its hand`);
  }
}
```

```ts
import type { NpcLook, NpcPlace } from '../worlds/types.ts';
import type { Facing } from './types.ts';

// Where a local stands, from its art (see NpcPlace): how far a standing
// one keeps everything off, where one behind its counter is cut, and which
// way it faces on screen.

// A standing local keeps this far from every footprint (units round its
// feet); the room planner keeps the floor that far round it clear.
export const NPC_R = 1.5;

// Where a local's picture is cut, units over its feet (none with nothing
// in front of it): where its counter's top, `top` high from its back edge
// at v = `edge`, crosses it on screen. The view drops half a unit down the
// screen for each unit nearer (see worlds/types.ts), so an edge `edge - v`
// nearer than the local shows half of that lower.
export function cutOf(pl: NpcPlace): number | undefined {
  if (pl.mode === 'standing' || pl.top === undefined || pl.edge === undefined) return undefined;
  return pl.top - (pl.mode === 'seated' ? pl.z : 0) - (pl.edge - pl.v) / 2;
}

// Which way a local with look `look` faces on screen at a station backed
// onto (or built facing) `wall`: out (+v) and along (+u) are toward the
// viewer, its front to us, turned screen left or right by the wall's frame
// (+v is +y on the right wall, down the screen to the left; +x on the left
// wall, down to the right); back (-v) shows its back.
export function facingOf(wall: 'left' | 'right', look: NpcLook = 'out'): Facing {
  if (look === 'back') return { back: true, flip: wall === 'left' };
  return { back: false, flip: (look === 'out') === (wall === 'right') };
}
```

```ts
import type { Npc, NpcAct, NpcLoop, Puppet, Swing } from '../../worlds/types.ts';

// The acts every local shares (see Npc in worlds/types.ts): a wave, a
// cheer, a flinch, applause, a word, a nod, handing over what it serves
// and beckoning someone over. Each drives the same puppet for every local
// with nothing drawn of its own, and starts and ends at rest, so it slots
// in between frames of the local's work. Arm 0 is the near one (it hands
// things over), arm 1 the far one, on the side the local faces (it waves
// and beckons).

export const TAU = Math.PI * 2;
export type SharedAct = Exclude<NpcAct, 'work' | 'show' | 'celebrate'>;

// Arms hanging easy, a soft bend at the elbow.
const HANG: Swing = { sh: 0.12, el: 0.2 };
const swing = (sh: number, el: number): Swing => ({ sh: HANG.sh + sh, el: HANG.el + el });
const TALK: ReadonlyArray<Puppet['mouth']> = ['open', 'smile', 'o', 'open', 'closed'];

// A local at rest: standing easy, eyes open, a small smile.
export function rest(): Puppet {
  return { act: 'work', u: 0, bob: 0, lean: 0, tilt: 0, arms: [HANG, HANG], eyes: 'open', mouth: 'smile', hold: false };
}

// Smoothstep from a to b.
export function ease(u: number, a: number, b: number): number {
  const k = Math.max(0, Math.min(1, (u - a) / (b - a)));
  return k * k * (3 - 2 * k);
}

// In and out: 0 at either end of the loop, 1 from a to b.
export function env(u: number, a = 0.2, b = 0.8): number {
  return ease(u, 0, a) - ease(u, b, 1);
}

// 0..1..0 over [a, b] of the loop.
export function bump(u: number, a: number, b: number): number {
  return u <= a || u >= b ? 0 : Math.sin(((u - a) / (b - a)) * Math.PI);
}

export const ACTS: Record<SharedAct, NpcLoop> = {
  // the far hand up, waving
  wave: {
    secs: 1.2,
    frames: 8,
    pose(u) {
      const k = env(u, 0.2, 0.85);
      return { ...rest(), tilt: -0.04 * k, arms: [HANG, swing(2.5 * k, k * (0.45 + 0.35 * Math.sin(u * TAU * 3)))], eyes: k > 0.5 ? 'happy' : 'open' };
    },
  },
  // both hands up and a little hop
  cheer: {
    secs: 1.2,
    frames: 8,
    pose(u) {
      const k = env(u, 0.2, 0.8);
      const up = swing(2.75 * k, -0.1 * k);

  if (act === 'show') return n.show ?? n.work;

}
```

```ts
import type { Npc, Puppet } from '../../worlds/types.ts';
import { move, mul, turn, type Sketch } from '../figure/paint.ts';

// A local from its parts and its puppet (see Npc in worlds/types.ts), in
// the figures' units (see art/figure/rig.ts): origin between its feet on
// the floor, x toward where it faces, y down. Its body bobs and leans about
// its feet; its head turns about its neck; each arm swings at the shoulder
// and bends at the elbow; the near hand holds out what it serves. Parts
// are recorded back to front for the view, then painted by the sprites'
// painter (see art/figure/paint.ts): from the front the near arm (0) goes
// over everything, the far one (1) behind the body while it hangs, over it
// once it swings forward (FORE) and over the head once raised (HIGH); from
// behind an arm swung forward is hidden behind the body, and arm 1 is the
// near one.

// Room for any local in any act (units round the point between its feet):
// up to 16 tall, bobbing, arms up, its legs hanging off a seat, what it
// serves held out.
export const NPC_BOX = { x0: -10, x1: 10, y0: -21, y1: 4 } as const;
const FORE = 0.6;
const HIGH = 2.2;

export function buildNpc(sk: Sketch, n: Npc, p: Puppet, back: boolean): void {
  const b = n.bones;
  const parts = n.parts;
  sk.push(mul(move(0, -p.bob), turn(p.lean)));
  const arm = (k: 0 | 1) => {
    const [sx, sy] = b.shoulders[k];
    sk.at(mul(move(sx, sy), turn(-p.arms[k].sh)), () => {
      parts.upper(sk, p, k, back);
      sk.at(mul(move(0, b.upper), turn(-p.arms[k].el)), () => {
        parts.fore(sk, p, k, back);
        if (k === 0 && p.hold && n.serve) sk.at(move(0, b.fore), () => n.serve!.draw(sk));
      });
    });
  };
  const body = () => parts.body(sk, p, back);
  const head = () => sk.at(mul(move(b.neck[0], b.neck[1]), turn(p.tilt)), () => parts.head(sk, p, back));
  const far = p.arms[1].sh;
  if (back) {
    // arm 0 is the far one from behind: under the body, forward or not
    if (far >= FORE) arm(1);
    arm(0);
    body();
    head();
    if (far < FORE) arm(1);
  } else {
    if (far < FORE) arm(1);
    body();
    if (far >= FORE && far < HIGH) arm(1);
    head();
    if (far >= HIGH) arm(1);
    arm(0);
  }
  sk.pop();
}
```

```ts
import type { NpcEyes, NpcMouth } from '../../worlds/types.ts';
import type { Ctx, Sketch } from '../figure/paint.ts';
import type { Color, Pen } from '../types.ts';

// A local's face, front on, in the figures' style (see art/figure/head.ts):
// two eyes `gap` apart on a row at y (the near one, toward -x, a little
// bigger), a mouth `drop` under the row. Open eyes are dark ovals (`r`
// across, a third taller) with a glint toward the light; a blink and shut
// eyes a lid line; happy ones an arc. The mouth: closed, a line; a smile,
// a curve; open, a dark oval with a tongue; o, a small round one.
export type FaceOpts = { x: number; y: number; eyes: NpcEyes; mouth: NpcMouth; gap?: number; r?: number; drop?: number; iris?: Color };

const TAU = Math.PI * 2;
const MOUTH = '#7a2e3b';
const TONGUE = '#ff8f8f';
const WHITE = '#ffffff';
const lw = (c: Ctx, k = 1) => Math.max(c.line * k, 1 / c.px);

export function face(sk: Sketch, o: FaceOpts): void {
  const gap = o.gap ?? 2.3;
  const r = o.r ?? 0.5;
  const drop = o.drop ?? 1.3;
  const iris = o.iris ?? '#2a2030';
  sk.draw((p, c) => {
    p.lineCap = 'round';
    p.lineJoin = 'round';
    p.strokeStyle = c.ink;
    eye(p, c, o.x - gap / 2, o.y, r, o.eyes, iris);
    eye(p, c, o.x + gap / 2, o.y, r * 0.9, o.eyes, iris);
    mouth(p, c, o.x + 0.05, o.y + drop, o.mouth);
  });
}

function eye(p: Pen, c: Ctx, x: number, y: number, r: number, kind: NpcEyes, iris: Color): void {
  const ry = r * 1.4;
  if (kind === 'blink' || kind === 'shut') {
    p.beginPath();
    p.moveTo(x - r * 1.05, y + 0.05);
    p.quadraticCurveTo(x, y + (kind === 'shut' ? 0.42 : 0.28), x + r * 1.05, y + 0.05);
    p.lineWidth = lw(c, 1.15);
    p.stroke();
    return;
  }
  if (kind === 'happy') {
    p.beginPath();
    p.moveTo(x - r * 1.05, y + 0.2);
    p.quadraticCurveTo(x, y - 0.5, x + r * 1.05, y + 0.2);
    p.lineWidth = lw(c, 1.25);
    p.stroke();
    return;
  }
  p.beginPath();
  p.ellipse(x, y, r, ry, 0, 0, TAU);
  p.fillStyle = iris;
  p.fill();
  p.beginPath();
  p.arc(x + c.lx * r * 0.4, y + c.ly * ry * 0.4, Math.max(r * 0.42, 0.55 / c.px), 0, TAU);
  p.fillStyle = WHITE;
  p.fill();
}

function mouth(p: Pen, c: Ctx, x: number, y: number, kind: NpcMouth): void {
  if (kind === 'open' || kind === 'o') {
    const shape = () => {
      p.beginPath();
      if (kind === 'open') p.ellipse(x, y + 0.2, 0.4, 0.44, 0, 0, TAU);
      else p.ellipse(x, y + 0.12, 0.24, 0.29, 0, 0, TAU);
    };
    shape();
    p.fillStyle = MOUTH;
    p.fill();
    if (kind === 'open' && c.px > 5) {
      p.save();
      p.clip();
      p.beginPath();
      p.ellipse(x, y + 0.62, 0.42, 0.3, 0, 0, TAU);
      p.fillStyle = TONGUE;
      p.fill();
      p.restore();
    }
    shape();
    p.lineWidth = lw(c, 0.85);
    p.stroke();
    return;
  }
  p.beginPath();
  if (kind === 'closed') {
    p.moveTo(x - 0.35, y + 0.1);
    p.lineTo(x + 0.35, y + 0.1);
  } else {
    p.moveTo(x - 0.42, y - 0.02);
    p.quadraticCurveTo(x, y + 0.4, x + 0.42, y - 0.02);
  }
  p.lineWidth = lw(c);
  p.stroke();
}
```

```ts
// Where each of the world's locals stands (see WorldDef.npcs): one behind
// its counter or seated, inside its station where its art says; one
// standing, where its art says if that floor is free (NPC_R clear of every
// prop and supply pile and off the plazas, 3 from the stations' spots (8
// from the way in's), 3 from the spots idlers like, out of the yard, 5 off
// the hub, and apart from the other standing ones), else left out, as
// decor is. Whoever it serves stands a step out in front of it (past its
// station's front for one inside it), the next a step along, each where
// the floor is free (else none); a show's crowd rings a point further out.
function placeNpcs(world: WorldDef, L: Layout, props: readonly PlacedProp[], pois: readonly Poi[], supply: readonly Rect[]): PlacedNpc[] {
  const rects = [...props.map(footprint), ...supply];
  const plazas = buildSites(L);
  const h = hub(L);
  const yd = yard(L);
  const clear = (s: Spot, m: number, plaza: number) =>
    s.x >= L.T + 1 && s.y >= L.T + 1 && s.x <= L.W - 2 && s.y <= L.D - 2 && !rects.some((r) => within(r, s.x, s.y, m)) && plazas.every((b) => Math.hypot(b.x - s.x, b.y - s.y) >= b.r + plaza);
  const out: PlacedNpc[] = [];
  const free = (s: Spot) =>
    clear(s, NPC_R, 2) &&
    L.slots.every((q) => Math.hypot(q.spot.x - s.x, q.spot.y - s.y) >= (q.kind === 'entrance' ? 8 : 3)) &&
    pois.every((q) => Math.hypot(q.x - s.x, q.y - s.y) >= 3) &&
    Math.hypot(yd.x - s.x, yd.y - s.y) >= yd.r + 1 &&
    Math.hypot(h.x - s.x, h.y - s.y) >= 5 &&
    out.every((o) => o.mode !== 'standing' || Math.hypot(o.x - s.x, o.y - s.y) >= 2 * NPC_R + 1);
  (world.npcs ?? []).forEach((n, k) => {
    const prop = props.findIndex((p) => p.slot?.kind === n.station);
    if (prop < 0) return;
    const p = props[prop];
    const pl = n.place;
    const [x, y] = toWorld(p, pl.u, pl.v, 0);
    if (pl.mode === 'standing' && !free({ x, y })) return;
    const fv = pl.mode === 'standing' ? Math.max(pl.v, p.dep) + 3 : p.dep + 2.5;
    const spot = (u: number): Spot | null => {
      const [sx, sy] = toWorld(p, u, fv, 0);
      return clear({ x: sx, y: sy }, 1.2, 1) ? { x: sx, y: sy } : null;
    };
    const front = spot(pl.u);
    const wait = front && (spot(pl.u + 4) ?? spot(pl.u - 4));
    const [rx, ry] = toWorld(p, pl.u, fv + RING_OUT, 0);
    const placed: PlacedNpc = { k, station: n.station, prop, mode: pl.mode, wall: p.wall, x, y, z: pl.mode === 'seated' ? pl.z : 0, facing: facingOf(p.wall, pl.look), front, wait, ring: { x: rx, y: ry } };
    const cut = cutOf(pl);
    if (cut !== undefined) placed.cut = cut;
    out.push(placed);
  });
  return out;
}
```

```ts
      if (this.react(l, l.art.celebrate ? 'celebrate' : 'cheer', c, d)) this.emote(l, this.rng.chance(0.5) ? 'star' : 'heart', c + d, 1.6);

  }

  flinch(x: number, y: number, c: number): void {

      if (dist(l.at, { x, y }) > REACT_R) continue;
      const d = this.rng.range(0, 0.15);
      if (this.react(l, 'flinch', c, d)) this.emote(l, 'excl', c + d + 0.3, 1.6);
    }
  }

  // Someone's role levelled up: they applaud.
  applaud(c: number): void {
    for (const l of this.all) this.react(l, 'applaud', c, this.rng.range(0.1, 0.5));
  }

  // ── per frame ─────────────────────────────────────────────────────────
  // Acts and emotes over are dropped.
  update(life: Life, _actors: readonly Actor[]): void {
    const c = life.clock;
    for (const l of this.all) {
      l.acts = l.acts.filter((q) => q.until > c);
      l.emotes = l.emotes.filter((e) => e.until > c);
    }
  }

  // What local l is doing at life clock c, and the frame of it: the act
  // under way (a show loops, the rest play once), else its work, each local
  // at a phase of its own so the three are not in step.
  doing(l: Local, c: number): { act: NpcAct; frame: number } {
    const a = l.acts.find((q) => q.at <= c && c < q.until);
    if (!a) {
      const w = l.art.work;
      return { act: 'work', frame: Math.floor(frac(c / w.secs + l.k * 0.37) * w.frames) % w.frames };
    }
    const lp = loopOf(l.art, a.act);
    const k = (c - a.at) / lp.secs;
    return { act: a.act, frame: a.act === 'show' ? Math.floor(frac(k) * lp.frames) % lp.frames : Math.min(lp.frames - 1, Math.floor(k * lp.frames)) };
  }

  frames(c: number): NpcFrame[] {

      const p = l.at;
      const { act, frame } = this.doing(l, c);
      const f: NpcFrame = { k: l.k, x: p.x, y: p.y, z: p.z, top: p.z + l.art.tall, facing: p.facing, act, frame, prop: p.prop, on: p.mode !== 'standing', works: p.station !== 'entrance', shadow: p.mode === 'standing' };
      if (p.cut !== undefined) f.cut = { h: p.cut, slope: p.wall === 'right' ? 0.5 : -0.5 };
      const e = l.emotes.find((q) => q.born <= c && c < q.until);
      if (e) f.emote = { kind: e.e, t: c - e.born };
      return f;
    });
  }

  // Lines `act` up for l, `delay` from now or once all it has lined up is
  // over, whichever is later (nothing under way is cut off); none past
  // MAX_ACTS. Whether it was.
  private react(l: Local, act: NpcAct, c: number, delay: number): boolean {
    if (l.acts.length >= MAX_ACTS) return false;
    const at = Math.max(c + delay, ...l.acts.map((q) => q.until));
    l.acts.push({ act, at, until: at + loopOf(l.art, act).secs });
    return true;
  }

  // Shows `e` over l from `born`, for `secs`.
  private emote(l: Local, e: Emote, born: number, secs: number): void {
    l.emotes.push({ e, born, until: born + secs });
    if (l.emotes.length > 3) l.emotes.shift();
  }
}
```

```ts
export function npcSprite(world: WorldDef, n: NpcFrame, s: number, ink: string): Sprite {
  const art = world.npcs?.[n.k];
  if (!art) return { img: new Canvas(1, 1), ax: 0, ay: 0 };

// Sprite sp with all it paints under a counter's top edge cleared (the
// line `h` pixels over the anchor, falling `slope` pixels a pixel to the
// right), cropped again round what is left, the anchor kept.
function cutAt(sp: Sprite, h: number, slope: number): Sprite {
  const { width: w, height: H } = sp.img;
  const c = new Canvas(w, H);
  c.data.set(sp.img.data);
  for (let x = 0; x < w; x++) {
    const from = Math.max(0, Math.ceil(sp.ay - h + slope * (x + 0.5 - sp.ax) - 0.5));
    for (let y = from; y < H; y++) c.data.fill(0, (y * w + x) * 4, (y * w + x) * 4 + 4);
  }
  return crop(c, sp.ax, sp.ay);
}
```

```ts
  // An animated prop drawn whole on its own (world pixels), again per
  // ambient step (each prop at its own phase) or when worked or left.
  private animPic(it: Item, f: SceneFrame, l: Layer, s: number, t: Tint): Vol {
    const { p, i, active } = it.anim!;
    const tick = Math.floor(f.t * AMBIENT_FPS + phaseOf(i));
    return this.vol(it.id, `${l.key}|${tick}|${active ? 1 : 0}`, () => this.animDrawn(p, i, f, l, s, f.t, active, t));
  }

  // An animated prop a local works (see SceneFrame.npcs): its motion goes
  // round a loop of CYCLE steps, each drawn once at this scale and kept, a
  // picture the terminal keeps too. Worked all the time, it would send a
  // new picture every ambient step; this way, once round, it is only
  // placed.
  private cyclePic(it: Item, f: SceneFrame, l: Layer, s: number, t: Tint): { pic: Pic; x: number; y: number } | null {
    const { p, i } = it.anim!;
    const step = cycleStep(f.t, i);
    const key = `${i}|${step}`;
    let c = l.cycles.get(key);
    if (c === undefined) {
      const d = this.animDrawn(p, i, f, l, s, step / AMBIENT_FPS, true, t);
      l.cycles.set(key, (c = d ? { pic: fresh(d.img), x: d.x, y: d.y } : null));
    }
    return c;
  }

  // Prop p (the i-th) drawn whole at clock `time`, worked or not (world
  // pixels), cropped: light it lays on with 'screen' is lifted off the base
  // under it (see lift); tinted.
  private animDrawn(p: PlacedProp, i: number, f: SceneFrame, l: Layer, s: number, time: number, active: boolean, t: Tint): Drawn {
    this.stats.animated++;
    l.warmed.add(i);
    const rel = (u: number, v: number, z: number): [number, number] => {
      const [x, y, zz] = toWorld(p, u, v, z);
      return [(x - y) * s, ((x + y) * s) / 2 - zz * s];
    };
    const B = new Bounds(TILE, TILE);
    this.drawProp(B, p, rel, s, time, active);
    if (!(B.x1 > B.x0 && B.y1 > B.y0)) return null;
    const { x0, y0, x1, y1 } = B;
    const at = (u: number, v: number, z: number): [number, number] => {
      const q = rel(u, v, z);
      return [q[0] - x0, q[1] - y0];
    };
    let img = new Canvas(x1 - x0, y1 - y0);
    this.drawProp(img, p, at, s, time, active);
    if (B.light) {
      const under = this.ground(f, l, x0, y0, x1 - x0, y1 - y0);
      const onto = copyOf(under);
      this.drawProp(onto, p, at, s, time, active);
      img = lift(img, onto, under);
    }
    const crop = cropped(img);
    if (!crop) return null;
    if (t) tintAll(crop.img.data, t.rgb, t.k);
    return { img: crop.img, x: x0 + crop.x, y: y0 + crop.y };
  }
```

```ts
import { ACTS, loopOf } from '../art/npc/acts.ts';
import type { Npc, NpcAct, WorldDef } from '../worlds/types.ts';
import type { Emote } from './character.ts';
import type { NpcFrame } from './frame.ts';
import type { Life } from './life.ts';
import { Rng, hashString } from './rng.ts';
import type { PlacedNpc } from './room.ts';
import type { Actor } from './stage.ts';
import type { Spot } from './types.ts';

// The locals (see Npc in worlds/types.ts): three people who are not agents,
// each working one of a world's stations all the time. What each is doing:
// its work, always, and over it the acts life gives it, one after another
// (one lined up waits for the one under way, so nothing is cut off; none
// during a show): a wave for someone walking in, a cheer for a finish, a
// flinch at a bang, applause for a level-up. One with something to serve
// serves those who come for it in turn, one at a time, at its counter or
// beside it (see Life's order and coffee errands); one with a show puts it
// on now and then, the idle agents free for it gathering round (see
// perform and Life.watch); an idle agent passing one free for a word may
// stop for one (see Life.natters). Everything comes from the world's
// seeded Rng and the life clock: a run plays the same every time.

// A serve is the shared hand-over (seconds); one waiting its turn at a
// counter goes without after SERVE_WAIT (the one ahead served, then itself,
// and an act under way when it came).
export const SERVE_S = ACTS.handOver.secs;
export const SERVE_WAIT = 2 * SERVE_S + 2;
// How far a bang carries to a local (units, as for the agents in life.ts).
const REACT_R = 40;
// At most this many acts lined up for a local.
const MAX_ACTS = 4;
// A word: an idle agent passing within NATTER_R of where a free local
// serves may stop (NATTER_CHANCE once a pass: no other roll for NATTER_LOOK
// seconds), at most once every NATTER_EVERY seconds an agent, for NATTER_S.
export const NATTER_R = 6;
export const NATTER_CHANCE = 0.35;
export const NATTER_LOOK = 8;
export const NATTER_EVERY = 60;
export const NATTER_S = 5;
// Shows: one every SHOW_EVERY seconds (the first as long in) while at
// least SHOW_MIN idle agents are awake (else a look again SHOW_RETRY
// later); it lasts SHOW_S; up to SHOW_MAX stand round it, APART from each
// other, joining as they come free (see Life.spare) until SHOW_JOIN before
// it ends.
export const SHOW_EVERY: readonly [number, number] = [120, 240];
export const SHOW_S = 20;
export const SHOW_MIN = 2;
const SHOW_MAX = 6;
const SHOW_RETRY = 10;
const SHOW_JOIN = 6;
const APART = 3;

// A local on duty: its art and where it stands (see PlacedNpc); its acts
// (the shared ones and its own, by the life clock: each from `at` to
// `until`, over its work) and the emotes over its head; those it serves in
// turn (`queue`, each where it stands: at the counter or beside it), the
// one it is serving and those it has served (until life lets them go);
// the show it is putting on (the spots of its ring, and who has gone to
// them), and the agent it is having a word with.
export type Local = {
  k: number;
  art: Npc;
  at: PlacedNpc;
  acts: Array<{ act: NpcAct; at: number; until: number }>;
  emotes: Array<{ e: Emote; born: number; until: number }>;
  queue: Array<{ id: string; spot: Spot }>;
  serving: { id: string; until: number } | null;
  served: Set<string>;
  show: { until: number; ring: Spot[]; crowd: string[] } | null;
  natter: { id: string; until: number } | null;
};

const frac = (v: number) => v - Math.floor(v);
const dist = (a: Spot, b: Spot) => Math.hypot(a.x - b.x, a.y - b.y);

export class Locals {
  readonly all: Local[];
  // Life clock time of the next show (see perform).
  nextShow: number;
  private rng: Rng;
  private standable: (s: Spot) => boolean;

  constructor(world: WorldDef, placed: readonly PlacedNpc[], standable: (s: Spot) => boolean, clock: number) {
    const arts = world.npcs ?? [];
    this.all = placed.map((at) => ({ k: at.k, art: arts[at.k], at, acts: [], emotes: [], queue: [], serving: null, served: new Set<string>(), show: null, natter: null }));
    this.rng = new Rng(hashString(world.id) ^ 0x10ca1);
    this.standable = standable;
    this.nextShow = clock + this.rng.range(SHOW_EVERY[0], SHOW_EVERY[1]);
  }

  // Local k (an index into its world's), if it is on duty.
  of(k: number): Local | undefined {
    return this.all.find((l) => l.k === k);
  }

  // ── serving ───────────────────────────────────────────────────────────
  // The nearest local with something to serve (a drink, for `drink`), no
  // show on and room at its counter.
  counter(a: Spot, drink = false): number | null {
    let best: Local | null = null;
    for (const l of this.all) {
      const s = l.art.serve;
      if (!s || (drink && !s.drink) || l.show || !this.spotFor(l)) continue;
      if (!best || dist(l.at, a) < dist(best.at, a)) best = l;
    }
    return best ? best.k : null;
  }

  // `a` takes its place at local k's counter: where to stand, or null when
  // there is no room.
  join(k: number, a: Actor): Spot | null {
    const l = this.of(k);
    const spot = l && !l.show ? this.spotFor(l) : null;
    if (!l || !spot) return null;
    l.queue.push({ id: a.info.id, spot });
    return spot;
  }

  // `a` is done with local k: out of its queue, its serve or its word over.
  leave(k: number, a: Actor): void {
    const l = this.of(k);
    if (!l) return;
    const id = a.info.id;
    l.queue = l.queue.filter((q) => q.id !== id);
    l.served.delete(id);
    if (l.serving?.id === id) {
      l.serving = null;
      l.acts = l.acts.filter((q) => q.act !== 'handOver');
    }
    if (l.natter?.id === id) l.natter = null;
  }

  // Whether local k has handed `a` what it serves.
  served(k: number, a: Actor): boolean {
    return !!this.of(k)?.served.has(a.info.id);
  }

  // Whether what local k serves is a drink.
  drink(k: number): boolean {
    return !!this.of(k)?.art.serve?.drink;
  }

  // ── shows and words ───────────────────────────────────────────────────
  // The show local k is putting on, if any.
  showOf(k: number): Local['show'] {
    return this.of(k)?.show ?? null;
  }

  // The nearest local free for a word (nothing under way or lined up,
  // nobody served or waiting, no show, no word on) whose counter (or
  // itself, with none) is within NATTER_R of `a`.
  near(a: Spot, c: number): number | null {
    let best: Local | null = null;
    let bd = NATTER_R;
    for (const l of this.all) {
      if (l.queue.length || l.serving || l.show || l.natter || l.acts.some((q) => q.until > c)) continue;
      const d = dist(l.at.front ?? l.at, a);
      if (d < bd) {
        best = l;
        bd = d;
      }
    }
    return best ? best.k : null;
  }

  // A word with `a` (see Life.natters): it answers, a speech mark and
  // talking, then nods and laughs.
  natter(k: number, a: Actor, c: number): void {
    const l = this.of(k);
    if (!l) return;
    l.natter = { id: a.info.id, until: c + NATTER_S };
    l.acts.push({ act: 'talk', at: c + 1.3, until: c + 1.3 + ACTS.talk.secs }, { act: 'nod', at: c + 3.2, until: c + 3.2 + ACTS.nod.secs });
    this.emote(l, 'speech', c + 1.3, 1.5);
    this.emote(l, 'note', c + 3.2, 1.4);
  }

  // ── what life tells them ──────────────────────────────────────────────
  // Someone walked in (at `a`): the local nearest the way in waves; each of
  // the others waves or nods about half the time.
  greet(a: Spot, c: number): void {
    let door: Local | null = null;
    for (const l of this.all) if (!door || dist(l.at, a) < dist(door.at, a)) door = l;
    for (const l of this.all) {
      if (l === door) this.react(l, 'wave', c, this.rng.range(0.2, 0.6));
      else if (this.rng.chance(0.5)) this.react(l, this.rng.chance(0.5) ? 'wave' : 'nod', c, this.rng.range(0.4, 1.2));
    }
  }

  // Someone finished: every local celebrates, its own way where it has one
  // (see Npc.celebrate), a star or a heart over it.
  celebrate(c: number): void {
    for (const l of this.all) {
      const d = this.rng.range(0.1, 0.6);
      if (this.react(l, l.art.celebrate ? 'celebrate' : 'cheer', c, d)) this.emote(l, this.rng.chance(0.5) ? 'star' : 'heart', c + d, 1.6);
    }
  }

  // A bang at (x, y): those near flinch with a start, then look (a '!').
  flinch(x: number, y: number, c: number): void {
    for (const l of this.all) {
      if (dist(l.at, { x, y }) > REACT_R) continue;
      const d = this.rng.range(0, 0.15);
      if (this.react(l, 'flinch', c, d)) this.emote(l, 'excl', c + d + 0.3, 1.6);
    }
  }

  // Someone's role levelled up: they applaud.
  applaud(c: number): void {
    for (const l of this.all) this.react(l, 'applaud', c, this.rng.range(0.1, 0.5));
  }

  // ── per frame ─────────────────────────────────────────────────────────
  // Acts and emotes over are dropped and those gone let go; a show over
  // ends with a bow, one under way draws those come free; the first there
  // of those waiting is served; a show starts when one is due (see
  // perform).
  update(life: Life, actors: readonly Actor[]): void {
    const c = life.clock;
    const byId = new Map(actors.map((a) => [a.info.id, a]));
    for (const l of this.all) {
      l.acts = l.acts.filter((q) => q.until > c);
      l.emotes = l.emotes.filter((e) => e.until > c);
      l.queue = l.queue.filter((q) => byId.has(q.id));
      for (const id of l.served) if (!byId.has(id)) l.served.delete(id);
      if (l.natter && (c >= l.natter.until || !byId.has(l.natter.id))) l.natter = null;
      if (l.show && c >= l.show.until) {
        l.show = null;
        this.react(l, 'nod', c, 0);
        this.emote(l, 'heart', c, 1.6);
      }
      if (l.show) this.gather(l, life, actors, c);
      this.serve(l, c, byId);
    }
    if (c >= this.nextShow && !this.all.some((l) => l.show)) this.perform(life, actors, c);
  }

  // What local l is doing at life clock c, and the frame of it: the act
  // under way (a show loops, the rest play once), else its work, each local
  // at a phase of its own so the three are not in step.
  doing(l: Local, c: number): { act: NpcAct; frame: number } {
    const a = l.acts.find((q) => q.at <= c && c < q.until);
    if (!a) {
      const w = l.art.work;
      return { act: 'work', frame: Math.floor(frac(c / w.secs + l.k * 0.37) * w.frames) % w.frames };
    }
    const lp = loopOf(l.art, a.act);
    const k = (c - a.at) / lp.secs;
    return { act: a.act, frame: a.act === 'show' ? Math.floor(frac(k) * lp.frames) % lp.frames : Math.min(lp.frames - 1, Math.floor(k * lp.frames)) };
  }

  // The locals as a frame shows them (see NpcFrame).
  frames(c: number): NpcFrame[] {
    return this.all.map((l) => {
      const p = l.at;
      const { act, frame } = this.doing(l, c);
      const f: NpcFrame = { k: l.k, x: p.x, y: p.y, z: p.z, top: p.z + l.art.tall, facing: p.facing, act, frame, prop: p.prop, on: p.mode !== 'standing', works: p.station !== 'entrance', shadow: p.mode === 'standing' };
      if (p.cut !== undefined) f.cut = { h: p.cut, slope: p.wall === 'right' ? 0.5 : -0.5 };
      const e = l.emotes.find((q) => q.born <= c && c < q.until);
      if (e) f.emote = { kind: e.e, t: c - e.born };
      return f;
    });
  }

  // Where the next one local l serves would stand: at its counter, or
  // beside it, whichever is free of the queue and standable; else null.
  private spotFor(l: Local): Spot | null {
    for (const s of [l.at.front, l.at.wait]) if (s && !l.queue.some((q) => q.spot === s) && this.standable(s)) return s;
    return null;
  }

  // A serve over: that one is served. Then, while nothing is under way and
  // no show is on, the first of those waiting who is there gets a
  // hand-over; whatever it had lined up waits for that.
  private serve(l: Local, c: number, byId: ReadonlyMap<string, Actor>): void {
    if (l.serving && c >= l.serving.until) {
      l.served.add(l.serving.id);
      l.serving = null;
    }
    if (l.serving || l.show || l.acts.some((q) => q.at <= c)) return;
    const next = l.queue.find((q) => {
      const a = byId.get(q.id);
      return !!a && !l.served.has(q.id) && !a.path.length && dist(a, q.spot) < 1.5;
    });
    if (!next) return;
    for (const q of l.acts) {
      q.at += SERVE_S;
      q.until += SERVE_S;
    }
    l.serving = { id: next.id, until: c + SERVE_S };
    l.acts.unshift({ act: 'handOver', at: c, until: c + SERVE_S });
  }

  // A show (see SHOW_EVERY): with SHOW_MIN idle agents awake, a local with
  // a show and nothing on (nobody served or waiting, no word) starts it,
  // and those free for it gather round (see gather). Nobody to give one,
  // too few awake or no room for a ring: it looks again a little later.
  private perform(life: Life, actors: readonly Actor[], c: number): void {
    const awake = actors.filter((a) => a.info.activity === 'idle' && a.state !== 'enter' && a.state !== 'leave' && !a.gone && !life.sleeping(a));
    const cast = this.all.filter((l) => l.art.show && !l.queue.length && !l.serving && !l.natter);
    const l = awake.length >= SHOW_MIN && cast.length ? this.rng.pick(cast) : null;
    const ring = l ? ringRound(l.at.ring, l.at, SHOW_MAX, this.standable) : [];
    if (!l || !ring.length) {
      this.nextShow = c + SHOW_RETRY;
      return;
    }
    this.nextShow = c + this.rng.range(SHOW_EVERY[0], SHOW_EVERY[1]);
    const until = c + SHOW_S;
    l.acts = [{ act: 'show', at: c, until }];
    l.show = { until, ring, crowd: [] };
    this.emote(l, l.art.show!.crowd === 'dance' ? 'note' : 'star', c, 1.6);
    this.gather(l, life, actors, c);
  }

  // The idle agents free for it (see Life.spare) join local l's show, the
  // nearest first, each to a spot of its ring of its own (see Life.watch),
  // while spots are left and until SHOW_JOIN before it ends.
  private gather(l: Local, life: Life, actors: readonly Actor[], c: number): void {
    const show = l.show;
    if (!show || c > show.until - SHOW_JOIN || show.crowd.length >= show.ring.length) return;
    const far = (a: Actor) => dist(a, l.at.ring);
    const free = actors.filter((a) => !show.crowd.includes(a.info.id) && life.spare(a)).sort((p, q) => far(p) - far(q));
    for (const a of free) {
      if (show.crowd.length >= show.ring.length) break;
      life.watch(a, l.k, show.ring[show.crowd.length], show.until);
      show.crowd.push(a.info.id);
    }
  }

  // Lines `act` up for l, `delay` from now or once all it has lined up is
  // over, whichever is later (nothing under way is cut off); none during a
  // show, none past MAX_ACTS. Whether it was.
  private react(l: Local, act: NpcAct, c: number, delay: number): boolean {
    if (l.show || l.acts.length >= MAX_ACTS) return false;
    const at = Math.max(c + delay, ...l.acts.map((q) => q.until));
    l.acts.push({ act, at, until: at + loopOf(l.art, act).secs });
    return true;
  }

  // Shows `e` over l from `born`, for `secs`.
  private emote(l: Local, e: Emote, born: number, secs: number): void {
    l.emotes.push({ e, born, until: born + secs });
    if (l.emotes.length > 3) l.emotes.shift();
  }
}

// Up to n spots round `c` for a crowd watching a show at `to`: 5 units out
// (then further), the side away from it first and round either way, but
// never across the side toward it (a ring open to the show), each one
// standable and APART from the others.
function ringRound(c: Spot, to: Spot, n: number, standable: (s: Spot) => boolean): Spot[] {
  const out: Spot[] = [];
  const away = Math.atan2(c.y - to.y, c.x - to.x);
  for (const r of [5, 7.5, 10]) {
    for (let k = 0; k <= 12 && out.length < n; k++) {
      const a = away + (k % 2 ? -1 : 1) * Math.ceil(k / 2) * (Math.PI / 8);
      const s = { x: c.x + Math.cos(a) * r, y: c.y + Math.sin(a) * r };
      if (standable(s) && out.every((o) => dist(o, s) >= APART)) out.push(s);
    }
  }
  return out;
}
```

```ts
// <world>: a registered world's id, or a world's module file (see

import { encodeRgb } from '../src/art/png.ts';
import { inkOf } from '../src/art/scene.ts';
import type { NpcFrame } from '../src/world/frame.ts';

import type { Facing } from '../src/world/types.ts';
import type { NpcAct, WorldDef } from '../src/worlds/types.ts';
import { loadWorld } from './scene-shot.ts';

export function sheet(world: WorldDef, s: number): { img: Canvas; notes: string[] } {
  const ink = inkOf(world);
  const npcs = world.npcs ?? [];
  const shared = Object.keys(ACTS) as NpcAct[];
  const cell = { w: 20 * s, h: 26 * s, feet: 22 * s };
  const bay = 40 * s;
  const at = (k: number, act: NpcAct, i: number, facing: Facing, cut?: number): NpcFrame => {
    const f: NpcFrame = { k, x: 0, y: 0, z: 0, top: npcs[k].tall, facing, act, frame: i, prop: 0, on: false, works: true, shadow: false };
    if (cut !== undefined) f.cut = { h: cut, slope: 0.5 };
    return f;
  };
  const rows = npcs.map((n) => {
    const pics: Array<[NpcAct, number]> = [];
    for (let i = 0; i < n.work.frames; i++) pics.push(['work', i]);
    if (n.show) for (let i = 0; i < n.show.frames; i += 2) pics.push(['show', i]);
    if (n.celebrate) for (let i = 0; i < n.celebrate.frames; i += 2) pics.push(['celebrate', i]);
    for (const a of shared) pics.push([a, Math.floor(loopOf(n, a).frames / 2)]);
    return pics;
  });
  const img = new Canvas(Math.max(1, ...rows.map((r) => r.length * cell.w), npcs.length * bay), Math.max(1, rows.length * cell.h + bay));
  rows.forEach((pics, k) =>
    pics.forEach(([act, i], j) => {
      const sp = npcSprite(world, at(k, act, i, { back: npcs[k].place.look === 'back', flip: false }), s, ink);
      img.drawImage(sp.img, j * cell.w + Math.round(cell.w / 2) - sp.ax, k * cell.h + cell.feet - sp.ay);
    }),
  );
  const notes: string[] = [];
  npcs.forEach((n, k) => {
    const art = world.stations[n.station];
    const pl = n.place;
    const P = frame(project(k * bay + (art.dep + 3) * s, rows.length * cell.h + (Math.min(art.height, 24) + 3) * s, s), 'right', 0, 0);
    art.draw({ pen: img, s, at: P, len: art.len, dep: art.dep, wall: 'right', island: false, t: 0.5, active: true, seed: 1 });
    const cut = cutOf(pl);
    const sp = npcSprite(world, at(k, 'work', 0, facingOf('right', pl.look), cut), s, ink);
    const [x, y] = P(pl.u, pl.v, pl.mode === 'seated' ? pl.z : 0);
    img.drawImage(sp.img, Math.round(x) - sp.ax, Math.round(y) - sp.ay);
    notes.push(`${n.name}: ${n.station}, ${pl.mode} at u ${pl.u}, v ${pl.v}${cut === undefined ? '' : `, cut ${cut.toFixed(2)} over its feet`}`);
  });
  return { img, notes };
}

if (import.meta.main) {
  const { values, positionals } = parseArgs({ allowPositionals: true, options: { s: { type: 'string', default: '8' } } });
  const [id, out] = positionals;
  if (!id || !out) {
    console.error('usage: node scripts/npc-sheet.ts <world> <out.png> [--s 8]');
    process.exit(2);

  writeFileSync(out, encodeRgb(img, 0xf4f0e8));
  for (const n of notes) console.log(n);
  console.log(`${out}: ${img.width} x ${img.height}`);
}
```

```ts
// Twenty at work in a world (its locals on, or off), played into the
// terminal: the bytes a step once every workstation is up (after 15
// seconds, over the next 3), and how many loop pictures and locals the last
// step placed.
function bytesAStep(theme: WorldDef, npcs = true): { bytes: number; loops: number; npcs: number } {
  const rate = 18;
  const world = new World({ theme, live: new StressSource(4, 4, START), demo: false, account: { name: 'you', plan: '' }, rootLabel: '~', start: START, images: true, view: 'scene', npcs });
  world.setCell(8, 16);
  world.resize(150, 46);
  const screen = new Screen(150, 46);
  const player = new ScenePlayer({ encode: (b, opaque) => (opaque ? encodeRgb(b, 0, 1) : encodeRgba(b, 1)) });
  let last: Plate | null = null;
  const build = player.scene.plate.bind(player.scene);
  player.scene.plate = (f) => (last = build(f));
  let bytes = 0;
  for (let k = 0; k < 18 * rate; k++) {
    const now = START + (k * 1000) / rate;
    world.tick(now);
    const out = player.step(world, screen, now);
    if (k >= 15 * rate) bytes += out.length;
  }
  const layers = (last as Plate | null)?.layers ?? [];
  return { bytes: bytes / (3 * rate), loops: layers.filter((l) => l.id.startsWith('loop:')).length, npcs: layers.filter((l) => l.id.startsWith('npc:')).length };
}
```

```ts
// A cocktail: a coupe on a stem, pink, a lime on its rim.
const cocktail: NpcServe = {
  name: 'cocktail',
  drink: true,
  draw(sk) {
    sk.limb([0, -0.1, 0, 0.9], 0.18, '#d3d2e2');
    sk.blob((p) => {
      p.moveTo(-0.75, -0.75);
      p.lineTo(0.75, -0.75);
      p.quadraticCurveTo(0.6, -0.05, 0, -0.05);
      p.quadraticCurveTo(-0.6, -0.05, -0.75, -0.75);
      p.closePath();
    }, C.pink, { dark: shade(C.pink, -0.25), d: 0.2 });
    sk.blob((p) => p.arc(0.65, -0.8, 0.25, 0, TAU), C.lime, { line: 0.5 });
  },
};

// Behind the bar: a shaker shaken over the counter in both hands, then a
// pour.
const bartenderWork: NpcLoop = {
  secs: 1.6,
  frames: 8,
  pose(u) {
    const shake = u < 0.6 ? Math.sin(u * TAU * 5) : 0;
    const pour = ease(u, 0.6, 0.7) - ease(u, 0.9, 1);
    return { ...rest(), tilt: 0.06 * pour, arms: [{ sh: 1.5 + 0.25 * shake - 0.3 * pour, el: 1.2 + 0.4 * pour }, { sh: 1.3 + 0.25 * shake, el: 1.3 }], eyes: shake > 0.8 ? 'happy' : 'open' };
  },
};
```
