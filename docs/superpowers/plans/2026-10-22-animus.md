# Animus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Zero-dependency animated terminal app that shows live Claude Code sessions/subagents as little characters working in switchable themed scenes.

**Architecture:** Node 26 runs `.ts` directly (type stripping). A read-only connector tails `~/.claude` session registry + JSONL transcripts into `AgentInfo[]`; a `Stage` turns agents into walking/working actors at theme stations; a cell `Screen` is diff-rendered to truecolor ANSI at ~18 fps. Themes are data-like modules (palette, art, backdrop/ambient draw fns).

**Tech Stack:** Node ≥ 23.6 (here 26.11), erasable TypeScript, `node:test`, `node:util.parseArgs`. No npm deps.

Spec: `docs/superpowers/specs/2026-10-22-animus-design.md`.

Conventions for every task:
- Erasable TS only: no `enum`, no constructor parameter properties, no `namespace`. Import with `.ts` extension. `import type` for type-only imports.
- Width-1 glyphs only. Forbidden: emoji (≥ U+1F000) and East-Asian-wide symbols (e.g. `☕ ⚡ ✨ ⭐ ✅ ❌ ⌛`). Lint helper `isWide(ch)` in `src/term/width.ts` is used by tests.
- Run all tests: `node --test "test/**/*.test.ts"` (no npm on this machine).
- Commit after each task with a conventional message.

### Task 6: Transcript tail + state machine

**Files:** `src/claude/transcript.ts`, `test/transcript.test.ts`
```ts
export type TranscriptState = { activity: Activity; detail: string; since: number; lastSeen: number; pending: Set<string>; ended: boolean; errorUntil: number; tools: number; prompted: boolean };
```

Rules: assistant record → per content block: `tool_use` adds `pending` id + activity/detail from Task 5; `thinking` → think/`thinking…`; non-empty `text` → talk/clip(text,40). `stop_reason==='end_turn'` and no pending → `ended=true`; any assistant block with tool_use → `ended=false`. user record: `tool_result` blocks remove pending id; `is_error:true` → activity `error`, detail `tool failed`, `errorUntil=ts+3000`; string content (prompt) → `ended=false`, `prompted=true`, think/`new task`. `lastSeen`=record timestamp. `since` updates when activity/detail changes. Non-object/unknown records ignored.
Tail: byte-offset incremental, Buffer remainder for partial lines (UTF-8 safe), malformed lines skipped, truncation resets to 0, first read of file larger than `maxInitialBytes` (default 262144) starts at `size-max` and drops the first partial line.

Tests: write temp JSONL with an assistant `tool_use Edit` record → state write/`Edit x.ts`, pending 1; append user tool_result → pending 0; append assistant `text` with `stop_reason:end_turn` → ended; error result → activity error; partial line appended in two chunks parsed once complete; malformed line skipped; large file honors `maxInitialBytes`.
