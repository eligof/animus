# Pet layer, part 2: talking to an agent — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enter on the selected agent's card grows it into a chat window beside its character. The window shows the agent's conversation, read from its transcript (the demo crew makes one up), and has an input line that posts the user's message into a live lead's session through Claude Code's cross-session inbox. Each message is followed until the session's transcript shows it.

**Architecture:** A `ChatReader` folds transcript records into `Bubble`s: replies, prompts, one-line tool steps, a thinking mark, and animus's own sent messages. The Claude source keeps one reader per tracked transcript and the demo source makes up its own; both sit behind the optional `AgentSource.chat / reach / send`. `claude/inbox.ts` finds a session's inbox socket in the registry and posts one framed line asynchronously, with a 5 s timeout. `followUp` then moves each sent message along on the World's ticks: sending, then sent, waiting, then delivered once the transcript shows it, or not seen after 60 s. The window is pure drawing and key handling: `ui/chat-lines.ts` lays out the lines, `ui/chat.ts` draws and handles keys, and `ui/chat-input.ts` edits the input line. The `World` keeps each agent's `ChatView`, routes keys to it, and never waits on a send.

**Tech Stack:** TypeScript on Node 26 (runs .ts directly), `node:test`, `node:net` for the Unix socket, no dependencies. Spec: `docs/superpowers/specs/2026-10-25-pet-layer-design.md` (section 3, Talking). Protocol: `docs/superpowers/specs/2026-10-25-inbox-protocol.md` (confirmed live by the spike).

**Decisions this plan makes (beyond the spec):**
1. **The closing tag is refused, not sent unwrapped.** Text containing `</cross-session-message` never leaves; the window shows `✗ not sent: the text holds </cross-session-message`. Sent unwrapped, the receiver would record the message with no `origin.name` or `body`, so animus could neither show it as "you →" nor confirm delivery. The agent would also see a message from an unnamed session. The protocol defines no escaping.
2. **Opening a fold:** Enter with an empty input opens the lowest folded message in view. That message's fold line is marked `[⏎] more`, and the keys line says `[⏎] more` too, so the target is never ambiguous. With a draft, Enter sends.
3. **Two focuses.** In the input every key types (q, t, digits…), and Esc moves to the log. In the log the app keys work again, Enter returns to the input, and Esc goes back to the card. Up, Down, PageUp and PageDown scroll in both. `ctrl-c` always quits. Moving the selection (Tab in the log) closes the chat.
4. **Agents that cannot take messages** are subagents, demo agents, and sessions without an inbox or with an old Claude Code. Their input still takes typing, and the separator says `can't send: <reason>`. Enter copies the text to the clipboard (OSC 52, written by the app) and the message shows `copied to the clipboard`, so it can be pasted into the agent's terminal.
5. **Delivery is matched by text and time:** the first `sent` record with the same trimmed text, timestamped no earlier than 5 s before the send, and not claimed by another message. A message not seen after 60 s shows `not seen`; it still turns `✓ delivered` if it shows up later. "Held for approval" cannot be told apart in part 2 (no receipt socket), so it shows as `not seen`.
6. **A paste is one message:** bracketed paste is turned on, so a paste's line breaks become spaces in the input and never send. A paste anywhere else is ignored, so pasted letters never act as keys.
7. **The chat opens in the dashboard view too**, docked, so terminals without images can talk.
8. **The card's bottom line** becomes `[⏎]talk  [c]heer  [tab] next  [esc]`, as in the spec mock. `[i] hide` no longer fits; `i` stays in the help. The help row reads `i / c / enter`, because the help box has no room for another row at 60x20.
9. **The window is about 60% of the scene's width** (44 to 72 cells) and `scene.h - 2` tall (8 to 24 rows). It is placed by the card's rules: beside the character on the side it last took, else the corner that covers the least of it, always inside the scene. The log is bottom-aligned, newest next to the input.
10. **A subagent's prompt** is labelled `task` (its lead wrote it); a lead's prompt is labelled `you`. Other sessions' peer messages, meta records, task notifications and slash-command records are left out. Thinking shows as `thinking…` only.
11. **The World finds an agent's source by who listed it**, not by who has its conversation, so a session whose transcript does not exist yet can still be sent to.

```ts
import type { Bubble } from '../agents.ts';
import { toolActivity, toolDetail } from './activity.ts';
import { INTERRUPTED, refused } from './transcript.ts';

// An agent's conversation as the chat window shows it, folded from its
// transcript records as the source reads them (see source.ts): its text
// replies, the prompts it was given, its tool steps as one-line rows, a
// mark where it thought (never what), and the messages animus posted into
// its session. Hook notes, command output, task notifications and other
// sessions' messages are left out. Transcript text is untrusted: it is
// kept as is here and made cell-safe where it is drawn (ui/chat-lines.ts).

// The name animus posts under (see inbox.ts).
export const SENDER = 'animus';
// Entries kept (the oldest dropped past it), and characters of one message.
const MAX_BUBBLES = 300;
const MAX_TEXT = 20_000;
// Tool calls whose result is still to come, at most.
const MAX_OPEN_TOOLS = 200;
// Prompts Claude Code writes itself: slash commands and their output,
// shell-mode input, subagent task notifications, reminders.
const SYSTEM = /^<(task-notification|command-name|command-message|command-args|local-command-stdout|local-command-stderr|local-command-caveat|system-reminder|bash-input|bash-stdout|bash-stderr)>/;

type Block = { type?: unknown; id?: unknown; name?: unknown; input?: unknown; text?: unknown; tool_use_id?: unknown; is_error?: unknown; content?: unknown };
type Rec = {
  type?: unknown;
  uuid?: unknown;
  timestamp?: unknown;
  isMeta?: unknown;
  origin?: { kind?: unknown; name?: unknown; body?: unknown };
  message?: { content?: unknown };
};

export class ChatReader {
  private list: Bubble[] = [];
  // Tool steps whose result is still to come, by tool call id.
  private tools = new Map<string, Bubble>();
  private seq = 0;

  // The conversation so far, oldest first. The caller only reads it.
  bubbles(): readonly Bubble[] {
    return this.list;
  }

  apply(rec: unknown): void {
    if (!rec || typeof rec !== 'object') return;
    const r = rec as Rec;
    if (r.type !== 'assistant' && r.type !== 'user') return;
    const t = typeof r.timestamp === 'string' ? Date.parse(r.timestamp) : NaN;
    const at = Number.isFinite(t) ? t : 0;
    const key = typeof r.uuid === 'string' && r.uuid ? r.uuid : `r${++this.seq}`;
    const content = r.message?.content;
    if (r.isMeta === true) {
      // Of the meta records, only animus's own messages, as posted.
      const o = r.origin;
      if (r.type === 'user' && o?.kind === 'peer' && o.name === SENDER && typeof o.body === 'string') this.add({ id: key, kind: 'sent', text: o.body, at });
      return;
    }
    if (r.type === 'assistant') {
      const blocks = Array.isArray(content) ? (content as Block[]) : [];
      blocks.forEach((b, i) => {
        const id = `${key}:${i}`;
        if (b?.type === 'text' && typeof b.text === 'string' && b.text.trim()) this.add({ id, kind: 'agent', text: b.text, at });
        else if (b?.type === 'thinking' || b?.type === 'redacted_thinking') this.add({ id, kind: 'thinking', text: '', at });
        else if (b?.type === 'tool_use') {
          const name = typeof b.name === 'string' && b.name ? b.name : 'tool';
          const input = b.input && typeof b.input === 'object' ? (b.input as Record<string, unknown>) : {};
          const step: Bubble = { id, kind: 'tool', text: toolDetail(name, input), at, activity: toolActivity(name), outcome: 'pending' };
          this.add(step);
          if (typeof b.id === 'string') this.open(b.id, step);
        }
      });
      return;
    }
    if (typeof content === 'string') {
      this.prompt(key, content, at);
      return;
    }
    if (!Array.isArray(content)) return;
    const blocks = content as Block[];
    let results = false;
    for (const b of blocks) {
      if (b?.type !== 'tool_result') continue;
      results = true;
      const id = typeof b.tool_use_id === 'string' ? b.tool_use_id : '';
      const step = this.tools.get(id);
      if (!step) continue;
      this.tools.delete(id);
      // A call refused before it ran (a hook, the rules, the user) or
      // interrupted is no failure.
      step.outcome = b.is_error !== true ? 'ok' : refused(b) ? 'refused' : 'failed';
    }
    if (results) return;
    const text = blocks.filter((b) => b?.type === 'text' && typeof b.text === 'string').map((b) => b.text as string).join('\n');
    if (text) this.prompt(key, text, at);
  }

  // A prompt, unless Claude Code wrote it (an interruption, a command).
  private prompt(id: string, text: string, at: number): void {
    const t = text.trimStart();
    if (!t || t.startsWith(INTERRUPTED) || SYSTEM.test(t)) return;
    this.add({ id, kind: 'user', text, at });
  }

  private add(b: Bubble): void {
    // One mark for a run of thinking.
    if (b.kind === 'thinking' && this.list[this.list.length - 1]?.kind === 'thinking') return;
    if (b.text.length > MAX_TEXT) b.text = `${[...b.text].slice(0, MAX_TEXT).join('')}…`;
    this.list.push(b);
    if (this.list.length > MAX_BUBBLES) this.list.splice(0, this.list.length - MAX_BUBBLES);
  }

  private open(id: string, step: Bubble): void {
    if (this.tools.size >= MAX_OPEN_TOOLS) this.tools.delete(this.tools.keys().next().value!);
    this.tools.set(id, step);
  }
}
```

```ts
import { listSessions, pidAlive } from './sessions.ts';
import type { LiveSession } from './sessions.ts';

// Posting the user's message into an agent's live session, through Claude
// Code's cross-session messaging (docs/superpowers/specs/2026-10-25-inbox-
// protocol.md): find the session's inbox socket in its registry entry,
// write one framed line to it, and follow the message until the session's
// transcript shows it. Only the text the user typed is sent, only to the
// session they picked. No token or `<pid>.key` file is ever read.

// Where a session takes messages, or why it does not.
export type Inbox = { ok: true; socket: string } | { ok: false; reason: string };

// A registry entry's inbox (undefined: no live session by that id).
export function inboxOf(s: LiveSession | undefined): Inbox {
  if (!s) return { ok: false, reason: 'no live session' };
  if (s.peerProtocol < 1) return { ok: false, reason: 'its Claude Code takes no messages' };
  if (!s.socket) return { ok: false, reason: 'messaging is off in its session' };
  return { ok: true, socket: s.socket };
}

// The inbox of the live session `sessionId`, looked up afresh in the
// registry (its process must be running).
export function findInbox(root: string, sessionId: string, alive: (pid: number, procStart?: string) => boolean = pidAlive): Inbox {
  return inboxOf(listSessions(root, alive).find((s) => s.sessionId === sessionId));
}
```

```ts
// The one line that posts `text` into session `sessionId`: a user message
// whose content names animus in the cross-session wrapper, at the default
// priority, with the session id the receiver checks against its own (a
// mismatch, as after a pid or socket was recycled, is dropped). Null for
// text holding the wrapper's closing tag: the receiver could not tell it
// from the wrapper, and unwrapped it would arrive with no name, so animus
// could neither show it as yours nor see it delivered.
export function frame(sessionId: string, text: string): string | null {
  if (text.includes(CLOSE_TAG)) return null;
  const content = `<cross-session-message from-name="${SENDER}">\n${text}\n</cross-session-message>`;
  return `${JSON.stringify({ type: 'user', message: { role: 'user', content }, priority: 'next', session_id: sessionId })}\n`;
}

// Writes `line` to the Unix socket at `path` and ends the connection. The
// socket never answers: a clean close is all a sender learns (delivered
// and dropped look the same; see followUp for what comes next).
export function post(path: string, line: string, timeoutMs = SEND_TIMEOUT_MS): Promise<SendResult> {
  return new Promise((resolve) => {
    let connected = false;
    let settled = false;
    const sock = connect({ path });
    const done = (r: SendResult) => {
      if (settled) return;
      settled = true;
      clearTimeout(timer);
      sock.destroy();
      resolve(r);
    };
    const timer = setTimeout(() => done({ ok: false, reason: 'timed out' }), timeoutMs);
    // Anything it says is read and dropped, so its end is seen.
    sock.on('data', () => {});
    sock.on('connect', () => {
      connected = true;
      sock.end(line);
    });
    sock.on('error', (e: NodeJS.ErrnoException) => done({ ok: false, reason: `${connected ? 'connection lost' : "can't connect"} (${e.code ?? 'error'})` }));
    sock.on('close', (hadError) => {
      if (!hadError) done(connected ? { ok: true } : { ok: false, reason: "can't connect" });
    });
  });
}

// Sends the user's `text` to the live session `sessionId`: framed, to the
// inbox its registry entry names right now.
export function sendTo(root: string, sessionId: string, text: string, o: { alive?: (pid: number, procStart?: string) => boolean; timeoutMs?: number } = {}): Promise<SendResult> {
  const line = frame(sessionId, text);
  if (!line) return Promise.resolve({ ok: false, reason: 'the text holds </cross-session-message' });
  const box = findInbox(root, sessionId, o.alive);
  if (!box.ok) return Promise.resolve({ ok: false, reason: box.reason });
  return post(box.socket, line, o.timeoutMs);
}
```

```ts
// A message the user sent (or copied) from the chat window, followed until
// its target's transcript shows it:
//   sending    the send is under way
//   waiting    written to the inbox, not in the transcript yet
//   delivered  the transcript shows it (`bubble`)
//   unseen     still not there SEEN_WITHIN_MS after sending (held for
//              approval in that terminal, or dropped)
//   failed     not sent (`reason`)
//   copied     the agent takes no messages (`reason`): the text went to
//              the clipboard instead
export type Outgoing = {
  id: string;
  text: string;
  at: number; // when it was sent
  status: 'sending' | 'waiting' | 'delivered' | 'unseen' | 'failed' | 'copied';
  reason: string;
  result?: SendResult; // the send's outcome once it settles, for followUp to take up
  bubble?: string; // delivered: the transcript entry that shows it
};

export const SEEN_WITHIN_MS = 60_000;
// The transcript's clock may run a little behind the moment of sending.
const CLOCK_SLACK_MS = 5000;

// Moves a message along: its settled send's outcome first, then the first
// of its target's 'sent' entries with its text, from about when it was
// sent, that no other message claimed (`claimed` collects them). Called on
// every tick, so the frame loop never waits on a send.
export function followUp(o: Outgoing, log: readonly Bubble[] | null, claimed: Set<string>, now: number): void {
  if (o.status === 'sending' && o.result) {
    if (!o.result.ok) {
      o.status = 'failed';
      o.reason = o.result.reason;
      return;
    }
    o.status = 'waiting';
  }
  if (o.status !== 'sending' && o.status !== 'waiting' && o.status !== 'unseen') return;
  const text = o.text.trim();
  const hit = log?.find((b) => b.kind === 'sent' && !claimed.has(b.id) && b.text.trim() === text && b.at >= o.at - CLOCK_SLACK_MS);
  if (hit) {
    o.status = 'delivered';
    o.bubble = hit.id;
    claimed.add(hit.id);
  } else if (o.status === 'waiting' && now - o.at >= SEEN_WITHIN_MS) o.status = 'unseen';
}
```

```ts
import type { Key } from '../term/terminal.ts';
import { cellSafe } from '../term/width.ts';

// The chat window's input line: one line of text and a cursor. Every
// printable key types itself (q types q, 1 types 1); the editing keys move
// and delete. Enter and Esc are the window's (see chat.ts).

export const MAX_INPUT = 2000; // characters

export class ChatInput {
  // A character (code point) each, so the cursor never splits one.
  private chars: string[] = [];
  cursor = 0;
  // The first half of a character that arrives as two keys (an emoji is
  // two UTF-16 halves, and the terminal reader makes a key of each).
  private high = '';

  get text(): string {
    return this.chars.join('');
  }

  // The line as the screen draws it: a cell per character, wide ones '?'.
  get shown(): string[] {
    return this.chars.map((c) => cellSafe(c) || '?');
  }

  clear(): void {
    this.chars = [];
    this.cursor = 0;
    this.high = '';
  }

  key(k: Key): void {
    switch (k.name) {
      case 'backspace':
        if (this.cursor > 0) this.chars.splice(--this.cursor, 1);
        return;
      case 'delete':
        this.chars.splice(this.cursor, 1);
        return;
      case 'left':
        this.cursor = Math.max(0, this.cursor - 1);
        return;
      case 'right':
        this.cursor = Math.min(this.chars.length, this.cursor + 1);
        return;
      case 'home':
      case 'ctrl-a':
        this.cursor = 0;
        return;
      case 'end':
      case 'ctrl-e':
        this.cursor = this.chars.length;
        return;
      case 'ctrl-u':
        this.chars.splice(0, this.cursor);
        this.cursor = 0;
        return;
    }
    if (k.ch) this.type(k.ch);
  }

  // Types one key's character at the cursor (control and zero-width ones
  // are dropped; the line holds at most MAX_INPUT).
  type(ch: string): void {
    if (/^[\ud800-\udbff]$/.test(ch)) {
      this.high = ch;
      return;
    }
    const c = /^[\udc00-\udfff]$/.test(ch) ? this.high + ch : ch;
    this.high = '';
    if ([...c].length !== 1 || /^[\ud800-\udfff]$/.test(c) || !cellSafe(c) || this.chars.length >= MAX_INPUT) return;
    this.chars.splice(this.cursor++, 0, c);
  }
}
```

```ts
import type { Bubble } from '../agents.ts';
import type { Outgoing } from '../claude/inbox.ts';
import { cellSafe } from '../term/width.ts';
import { fit } from './card.ts';
import { activityGlyph } from './chrome.ts';

// The chat window's lines: an agent's conversation, and the messages sent
// to it, laid out for a width. A speaker's name opens each message in a
// gutter, its text wrapped beside it; tool steps are one-line rows; a
// long message folds after FOLD lines until opened. Every line is
// cell-safe (see wrap), whatever the transcript held.
//
//   you    Fix the tokenizer edge case
//   nova   On it. I'll start by reading the code
//          around it.
//     ▶ $ npm test ✓
//     thinking…
//   you →  add a test too  ✓ delivered

export const FOLD = 6;
export const GUTTER = 7; // the speaker's column

// How a piece of a line is coloured (the window maps these to its palette).
export type Tone = 'ink' | 'dim' | 'name' | 'you' | 'good' | 'warn' | 'bad';
export type Seg = { text: string; tone: Tone };
export type Line = Seg[];
// A folded message's '… more' line, and which message it opens.
export type Fold = { line: number; id: string };
// The agent's name, and who prompts it ('you' for a lead, 'task' for a subagent).
export type Names = { agent: string; prompter: string };

const cells = (s: string) => [...s].length;
const pad = (s: string, n: number) => s + ' '.repeat(Math.max(0, n - cells(s)));

// Text as lines of at most `width` cells, as the screen draws it (cellSafe:
// control and zero-width characters dropped, wide ones '?', tabs spaces),
// broken at spaces where it can and mid-word where it must. Its own line
// breaks stay (a run of blank lines as one); blank ends go.
export function wrap(text: string, width: number): string[] {
  const w = Math.max(1, Math.floor(width));
  const out: string[] = [];
  for (const para of text.split('\n')) {
    let cs = [...para].map(cellSafe).filter(Boolean);
    while (cs.length && cs[cs.length - 1] === ' ') cs.pop();
    if (!cs.length) {
      if (out.length && out[out.length - 1] !== '') out.push('');
      continue;
    }
    while (cs.length > w) {
      let cut = cs.lastIndexOf(' ', w);
      if (cut <= 0) cut = w;
      out.push(cs.slice(0, cut).join('').trimEnd());
      cs = cs.slice(cut);
      while (cs[0] === ' ') cs.shift();
    }
    out.push(cs.join(''));
  }
  while (out.length && out[out.length - 1] === '') out.pop();
  return out;
}

// A sent message's state, at the end of its line.
export function status(o: Outgoing): Seg {
  switch (o.status) {
    case 'sending':
      return { text: 'sending…', tone: 'dim' };
    case 'waiting':
      return { text: 'sent, waiting', tone: 'dim' };
    case 'delivered':
      return { text: '✓ delivered', tone: 'good' };
    case 'unseen':
      return { text: 'not seen', tone: 'warn' };
    case 'failed':
      return { text: `✗ not sent: ${o.reason}`, tone: 'bad' };
    case 'copied':
      return { text: 'copied to the clipboard', tone: 'dim' };
  }
}

// The lines for `log` (oldest first) and the messages `sent` to it at
// `width` cells, those in `open` in full. A sent message the transcript
// shows is drawn there with its state; the rest go in by the time they
// were sent.
export function layoutChat(log: readonly Bubble[], sent: readonly Outgoing[], width: number, open: ReadonlySet<string>, names: Names): { lines: Line[]; folds: Fold[] } {
  const lines: Line[] = [];
  const folds: Fold[] = [];
  const textW = Math.max(1, width - GUTTER);
  const indent: Seg = { text: ' '.repeat(GUTTER), tone: 'dim' };
  const speech = (id: string, who: string, tone: Tone, text: string, mark: Seg | null) => {
    const all = wrap(text, textW);
    if (!all.length) all.push('');
    const folded = all.length > FOLD && !open.has(id);
    (folded ? all.slice(0, FOLD) : all).forEach((t, i) => lines.push([i === 0 ? { text: pad(fit(who, GUTTER - 1), GUTTER), tone } : indent, { text: t, tone: 'ink' }]));
    if (folded) {
      folds.push({ line: lines.length, id });
      lines.push([indent, { text: `… ${all.length - FOLD} more lines`, tone: 'dim' }]);
    }
    if (!mark) return;
    const m = { ...mark, text: fit(mark.text, textW) };
    const last = lines[lines.length - 1];
    if (last.reduce((n, sg) => n + cells(sg.text), 0) + 2 + cells(m.text) <= width) last.push({ text: '  ', tone: 'dim' }, m);
    else lines.push([indent, m]);
  };
  const step = (b: Bubble) => {
    const mark: Seg | null =
      b.outcome === 'ok' ? { text: ' ✓', tone: 'good' } : b.outcome === 'failed' ? { text: ' ✗', tone: 'bad' } : b.outcome === 'refused' ? { text: ' refused', tone: 'dim' } : null;
    const head = `  ${activityGlyph(b.activity ?? 'run')} `;
    const room = width - cells(head) - (mark ? cells(mark.text) : 0);
    lines.push([{ text: head, tone: 'dim' }, { text: fit(b.text, room), tone: 'dim' }, ...(mark ? [mark] : [])]);
  };
  const delivered = new Map(sent.filter((o) => o.status === 'delivered' && o.bubble).map((o) => [o.bubble!, o]));
  const waiting = sent.filter((o) => o.status !== 'delivered');
  let k = 0;
  const upTo = (t: number) => {
    for (; k < waiting.length && waiting[k].at <= t; k++) speech(waiting[k].id, 'you →', 'you', waiting[k].text, status(waiting[k]));
  };
  for (const b of log) {
    if (b.at > 0) upTo(b.at - 1);
    if (b.kind === 'agent') speech(b.id, names.agent, 'name', b.text, null);
    else if (b.kind === 'user') speech(b.id, names.prompter, 'you', b.text, null);
    else if (b.kind === 'sent') {
      const o = delivered.get(b.id);
      speech(b.id, 'you →', 'you', b.text, o ? status(o) : null);
    } else if (b.kind === 'tool') step(b);
    else lines.push([{ text: '  thinking…', tone: 'dim' }]);
  }
  upTo(Infinity);
  return { lines, folds };
}
```

```ts
import type { AgentInfo, Bubble } from '../agents.ts';
import type { Outgoing } from '../claude/inbox.ts';
import type { RGB } from '../term/color.ts';
import type { Rect, Screen } from '../term/screen.ts';
import { BOLD } from '../term/screen.ts';
import type { Key } from '../term/terminal.ts';
import type { Palette } from '../themes/types.ts';
import { CARD_H, CARD_W, drawFrame, fit, inks, placeCard } from './card.ts';
import type { Box, Placement, Side } from './card.ts';
import { ChatInput } from './chat-input.ts';
import { layoutChat } from './chat-lines.ts';
import type { Tone } from './chat-lines.ts';

// The chat window: the selected agent's card grown into its conversation
// (see chat-lines.ts), an input line at the bottom. Placed by the card's
// rules (beside its character, else the corner that covers the least of
// it, always inside the scene), as big as the scene allows up to CHAT_MAX.
//
//   ╭─ nova · lead ─────────────────────────────────╮
//   │ you    Fix the tokenizer edge case            │
//   │ nova   On it. I'll start by reading the code  │
//   │        around it.                             │

//   │ › and the docs▏                               │
//   ╰─ [⏎] send  [↑↓] scroll  [esc] leave ──────────╯

export const CHAT_MAX = { w: 72, h: 24 };

// The window's state for one agent, kept while it is closed so a draft and
// the messages sent stay.
export type ChatView = {
  id: string;
  // Where keys go: the input line, or the log (scrolling; Esc goes back
  // to the card).
  focus: 'input' | 'log';
  input: ChatInput;
  sent: Outgoing[];
  open: Set<string>; // messages shown in full
  top: number | null; // the first line shown (null: following the newest)
  // As of the last draw: the first line shown, the lines, the log's rows,
  // and the folded message Enter opens (the lowest in view).
  first: number;
  total: number;
  rows: number;
  more: string | null;
};

export function newChatView(id: string): ChatView {
  return { id, focus: 'input', input: new ChatInput(), sent: [], open: new Set(), top: null, first: 0, total: 0, rows: 0, more: null };
}

export type ChatOpts = {
  info: AgentInfo;
  log: readonly Bubble[];
  reach: string | null; // why it cannot be sent to (null: it can)
  color: RGB; // the agent's own colour
  palette: Palette;
};

const cells = (s: string) => [...s].length;

// The window's size in `scene`: some 60% of its width and nearly its
// height, never under the card's size nor over CHAT_MAX or the scene.
export function chatSize(scene: Rect): { w: number; h: number } {
  const w = Math.max(CARD_W, Math.min(CHAT_MAX.w, Math.floor(scene.w * 0.6)));
  const h = Math.max(CARD_H, Math.min(CHAT_MAX.h, scene.h - 2));
  return { w: Math.min(w, scene.w), h: Math.min(h, scene.h) };
}

// Moves the view `d` lines (up is negative), from where the last draw
// left it or the keys since; at the bottom it follows the newest again.
function scrollBy(v: ChatView, d: number): void {
  const last = Math.max(0, v.total - v.rows);
  const top = Math.max(0, Math.min(last, Math.min(v.top ?? last, last) + d));
  v.top = top >= last ? null : top;
}

// Draws the window for a character covering `box` (null: none in view;
// docked), on the `prefer` side when it fits, and says where it went
// (null: nowhere, the scene is smaller than the card). Notes in `v` what
// it showed, for the keys (see chatKey).
export function drawChat(s: Screen, scene: Rect, v: ChatView, o: ChatOpts, box: Box | null, prefer: Side | null = null): Placement | null {
  if (scene.w < CARD_W || scene.h < CARD_H) return null;
  const size = chatSize(scene);
  const at = placeCard(scene, box, prefer, size);
  const { x, y } = at;
  const { w, h } = size;
  const p = o.palette;
  const { bg, ink, edge, dim } = inks(p);
  const right = x + w - 1;
  const cx = x + 2; // content left
  const end = right - 1; // content limit (exclusive)
  const inner = end - cx;
  const tone: Record<Tone, RGB> = { ink, dim, name: o.color, you: p.accent, good: p.good, warn: p.warn, bad: p.bad };
  drawFrame(s, { x, y, w, h }, edge, ink, bg);
  // Top edge: whose conversation.
  s.put(cx, y, ' ', ink, bg);
  const nx = s.text(cx + 1, y, fit(o.info.name, 16), o.color, bg, BOLD, end);
  s.text(nx, y, ` · ${o.info.role} `, dim, bg, 0, end);
  // The log, between the top edge and the separator.
  const rows = h - 4;
  const { lines, folds } = layoutChat(o.log, v.sent, inner, v.open, { agent: o.info.name, prompter: o.info.role === 'sub' ? 'task' : 'you' });
  const last = Math.max(0, lines.length - rows);
  if (v.top !== null && v.top >= last) v.top = null;
  const first = v.top ?? last;
  Object.assign(v, { first, total: lines.length, rows, more: null });
  let moreAt = -1;
  for (const f of folds) {
    if (f.line >= first && f.line < first + rows) {
      v.more = f.id;
      moreAt = f.line;
    }
  }
  // Newest at the bottom, next to the input: a short log sits low.
  const shownN = Math.min(rows, lines.length - first);
  const ly = y + 1 + rows - shownN;
  for (let j = 0; j < shownN; j++) {
    let px = cx;
    for (const sg of lines[first + j]) px = s.text(px, ly + j, sg.text, tone[sg.tone], bg, sg.tone === 'name' ? BOLD : 0, end);
    if (first + j === moreAt) s.text(px, ly + j, '  [⏎] more', p.accent, bg, 0, end);
  }
  if (!lines.length) s.text(cx, y + rows, 'nothing said yet', dim, bg, 0, end);
  // The separator: why it cannot be sent to, and what is below the view.
  const sy = y + h - 3;
  for (let i = x + 1; i < right; i++) s.put(i, sy, '─', edge, bg);
  s.put(x, sy, '├', edge, bg);
  s.put(right, sy, '┤', edge, bg);
  const below = lines.length - (first + rows);
  const more = below > 0 ? ` ↓ ${below} more ` : '';
  if (o.reach) s.text(cx, sy, ` ${fit(`can't send: ${o.reach}`, inner - 2 - cells(more))} `, p.warn, bg, 0, end);
  if (more) s.text(end - cells(more), sy, more, dim, bg, 0, end);
  // The input line.
  const iy = y + h - 2;
  const typing = v.focus === 'input';
  s.text(cx, iy, '›', typing ? p.accent : dim, bg);
  const tx = cx + 2;
  const room = end - tx; // cells for the text and the cursor
  const chars = v.input.shown;
  if (typing) {
    const from = Math.max(0, v.input.cursor - (room - 1));
    s.text(tx, iy, chars.slice(from, from + room).join(''), ink, bg, 0, end);
    // The cursor: its cell inverted.
    const cur = tx + v.input.cursor - from;
    s.put(cur, iy, chars[v.input.cursor] ?? ' ', bg, ink);
    if (!chars.length) s.text(cur + 1, iy, o.reach ? 'type here; ⏎ copies it' : 'type a message', dim, bg, 0, end);
  } else {
    s.text(tx, iy, fit(chars.length ? chars.join('') : o.reach ? '⏎ to write (it is copied, not sent)' : '⏎ to write', room), dim, bg, 0, end);
  }
  // Bottom edge: the keys.
  const enter = !typing ? '[⏎] write' : !v.input.text.trim() && v.more ? '[⏎] more' : o.reach ? '[⏎] copy' : '[⏎] send';
  s.text(cx, y + h - 1, ` ${enter}  [↑↓] scroll  ${typing ? '[esc] leave' : '[esc] card'} `, dim, bg, 0, end);
  return at;
}

// What a key does in the chat window. Up, Down, PageUp and PageDown scroll
// in either focus. In the input every other key is the line's (q types q):
// Enter submits a draft or, with none, opens the message marked [⏎] more;
// Esc leaves the input for the log. In the log Enter goes back to the
// input, Home and End jump, Esc closes the window ('close'), and any other
// key is the app's ('pass').
export type ChatAction = 'submit' | 'close' | 'pass' | null;

export function chatKey(v: ChatView, k: Key): ChatAction {
  const page = Math.max(1, v.rows - 1);
  switch (k.name) {
    case 'up':
      scrollBy(v, -1);
      return null;
    case 'down':
      scrollBy(v, 1);
      return null;
    case 'pageup':
      scrollBy(v, -page);
      return null;
    case 'pagedown':
      scrollBy(v, page);
      return null;
  }
  if (v.focus === 'log') {
    switch (k.name) {
      case 'escape':
        return 'close';
      case 'enter':
        v.focus = 'input';
        return null;
      case 'home':
        v.top = 0;
        return null;
      case 'end':
        v.top = null;
        return null;
    }
    return 'pass';
  }
  if (k.name === 'escape') {
    v.focus = 'log';
    return null;
  }
  if (k.name === 'enter') {
    if (v.input.text.trim()) return 'submit';
    if (v.more) {
      // Opened in place: the view holds still while it grows.
      v.open.add(v.more);
      if (v.top === null) v.top = v.first;
    }
    return null;
  }
  v.input.key(k);
  return null;
}
```
